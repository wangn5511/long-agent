## 训练流程

### 1. 8类别训练（公开数据集）

```bash
export CUDA_VISIBLE_DEVICES=1
python imagenet.py \
  -a mobilenetv2 \
  -d /home/models/hagrid_labeled \
  -b 128 \
  -j 4 \
  --epochs 100 \
  --save-step 10 \
  --num-classes 8 \
  --lr-decay cos \
  --lr 0.05 \
  --wd 4e-5 \
  --width-mult 1.0 \
  --input-size 224 \
  --checkpoint /home/models/mobilenetv2/checkpoints_mbv2 \
  --pretrained /home/models/mobilenetv2/pretrained/mobilenetv2_1.0-0c6065bc.pth
```

## ONNX 导出

### 导出动态batch模型
```bash
python onnx_export_v2.py \
  --model mobilenetv2 \
  --dynamic-batch \
  --checkpoint /home/models/mobilenetv2/checkpoints/[模型路径]/model_best.pth.tar \
  --nb-classes [类别数] \
  --batch-size 1 \
  --img-size 224 \
  --output /home/models/mobilenetv2/checkpoints/[模型路径]/model_best_dynamic.onnx
```

### 导出固定batch模型

## 训练参数说明

- `-a`: 模型架构（mobilenetv2）
- `-d`: 数据集路径
- `-b`: batch size（128）
- `-j`: 数据加载线程数（4）
- `--epochs`: 训练轮数（100-200）
- `--num-classes`: 类别数（8 或 10）
- `--lr`: 学习率（0.05）
- `--lr-decay`: 学习率衰减策略（cos）
- `--wd`: 权重衰减（4e-5）
- `--input-size`: 输入图像尺寸（224）
- `--checkpoint`: 模型保存路径
- `--pretrained`: 预训练权重路径（从头训练时使用）
- `--resume`: 继续训练权重路径（微调时使用）
