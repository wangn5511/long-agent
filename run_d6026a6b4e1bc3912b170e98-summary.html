Fix before retraining

把分布式结果汇总目录显式设置到可写的 /mlops-output/.dist_test， 并增加一个 1 Epoch 的 8 卡 train→val 冒烟测试。它通过以后，再启动 100 Epoch 搜索。

Model direction

优先研究 CURSOR → NONE

基线中 CURSOR 的 81 条样本有 7 条被判为 NONE，是最集中的可解释误差。 下一轮应先查看这 7 条的动作幅度、时序长度与 gate 分数，再决定调阈值还是补困难样本。
